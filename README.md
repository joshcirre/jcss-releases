# JCSS downloads

**JCSS (Just Create Studio Software)** is a live studio for recording and streaming: cameras,
screens, graphics and audio, mixed and recorded already edited. You set it up and change it by
talking to the AI you already use (Claude or Codex).

This repository only holds releases. The app's source is private.

## Download

Get the newest version from **[Releases](https://github.com/joshcirre/jcss-releases/releases/latest)**:

- **Mac** (Apple Silicon, macOS 15 or later): `JCSS-<version>.dmg`. Open it and drag JCSS to
  Applications. It updates itself after that (JCSS › Check for Updates…).
- **Windows** (10 or 11, 64-bit): `JCSS-<version>-windows-x64.zip`. Unzip it anywhere and run
  `JCSS.exe`. Until the Windows build is code-signed, Windows may say "Windows protected your
  PC": choose **More info › Run anyway**.

JCSS is early software; expect rough edges. Feedback and problems: open an issue here.
