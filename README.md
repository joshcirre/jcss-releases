# JCSS downloads

JCSS is a live studio for recording and streaming. This repository only holds releases.

**Alpha software.** Expect bugs and changes that break projects. Report problems to
[jcss@joshcirre.com](mailto:jcss@joshcirre.com).

## Download

[Latest release](https://github.com/joshcirre/jcss-releases/releases/latest):

- **Mac** (Apple Silicon, macOS 15+): `JCSS-<version>.dmg`. Drag JCSS to Applications. It updates itself.
- **Windows** (10 or 11, 64-bit): `JCSS-<version>-windows-setup.exe`. If Windows warns, choose More info › Run anyway.
